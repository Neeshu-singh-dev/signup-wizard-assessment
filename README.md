# Signup Wizard Assessment

Responsive front-end implementation of the Signup Wizard assessment.

## Run locally

No build step is required. Open `index.html` directly in a browser or serve the folder with any static HTTP server.

Example:

```bash
npx serve .
```

## Included

- Landing page mechanism
- Terms & Conditions page
- Four-step progressive signup flow
- Email validation
- OTP validation and resend state
- Age 18+ validation
- Required field validation
- Numeric input constraints
- State → city → college dependent selects
- Loading states to prevent duplicate submission
- Toast/global error feedback
- Back/exit navigation
- Completion/success state
- Responsive mobile, tablet, and desktop layouts
